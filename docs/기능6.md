# 🎨 UI/UX 및 프론트엔드 기능 요구사항 명세서

## 1. 디자인 시스템 & 무드 (IT 대기업 사내 시스템 콘셉트)

* **전체적인 무드:** 토스(Toss), 라인(LINE)의 사내 어드민 툴 느낌의 깔끔하고 직관적인 **모던 미니멀(Modern Minimal)** 스타일
* **컬러 시스템:**
* **배경색 (Background):** 깨끗한 화이트 및 아주 밝은 그레이 (`#F8FAFC`)
* **포인트/강조색 (Primary):** 신뢰감을 주는 테크 블루 (`#2563EB`) 또는 활기찬 민트 (`#10B981`)
* **텍스트색 (Text):** 가독성이 높은 다크 차콜 (`#1E293B`) 및 서브 텍스트용 그레이 (`#64748B`)


* **디자인 컴포넌트 규칙 (Bootstrap 5 활용):**
* 모든 버튼과 카드, 인풋 창의 모서리는 부드럽고 둥글게 처리 (`rounded-3`, `rounded-lg`)
* 요소 간의 간격을 넓게 배치하여 시각적 피로도를 낮추고 고급스러운 사내 솔루션 느낌 연출 (`p-4`, `g-4`, `mb-4`)
* 중요한 데이터 영역(조별 카드 등)은 은은한 그림자 효과로 입체감 부여 (`shadow-sm`)

## 2. 화면별 상세 UI/UX 요구사항 (Jinja2 템플릿 구조)

### ① 공통 레이아웃 (`base.html`)

* **상단 네비게이션 바 (Navigation Bar):** * 좌측 상단에 서비스 로고(예: `🌱 JD-Match`) 배치
* 우측에 **[크루 신청]**, **[매칭 결과 조회]**, **[인사이트 게시판]**, **[관리자]** 메뉴 탭을 깔끔한 고딕 텍스트로 배치
* 현재 머무르고 있는 메뉴는 포인트 컬러(블루/민트)로 활성화 표시 (`.active`)
* 로그인 상태에 따라 **[로그인/로그아웃]** 버튼이 유연하게 스위칭되는 UX 구현



### ② 크루 신청 및 회원가입 페이지 (`signup.html`)

* **레이아웃:** 화면 중앙에 깔끔한 화이트 사각형 카드 UI 배치 (`max-width: 500px`)
* **UX 요소:**
* 각 입력창(`input`) 위에 명확한 레이블과 안내 문구 제공
* **입력 필드 스타일:** 테두리가 아주 연한 회색이며, 마우스를 올리거나 클릭 시 포인트 블루 컬러로 외곽선이 빛나는 UX 적용 (`form-control:focus`)
* **체크박스 스타일:** 목표 기업과 관심 기술 스택은 텍스트 입력이 아닌, Bootstrap 5를 활용해 다중 선택이 가능한 깔끔한 체크박스 목록(또는 버튼형 태그)으로 제공하여 사용자 편의성을 높임
* **제출 버튼:** 화면 너비를 꽉 채우는 볼드한 포인트 컬러 버튼 배치 (`btn-primary w-100`)



### ③ 로그인 페이지 (`login.html`)

* **UX 요소:** 회원가입 페이지와 통일감 있는 미니멀 사각형 카드 UI로 구성하여 인지 부하 최소화

### ④ 관리자 대시보드 페이지 (`admin.html`)

* **레이아웃:** 상단에 대시보드 요약 지표 카드를 배치하고, 하단에 전체 명단 테이블을 배치하는 2단 구조
* **UX 요소:**
* **요약 카드 (KPI 위젯):** `[총 신청 인원: N명]`, `[현재 편성된 조: N개]`를 큰 숫자로 시각화하여 상단에 배치
* **크루 현황 테이블 (`table`):** 부트스트랩의 깔끔한 가로선 테마(`table-hover`)를 적용하고, 닉네임, 목표 기업, 관심 기술 키워드가 한눈에 들어오도록 열 너비 조정
* **액션 플로팅 바:** 대시보드 하단 혹은 상단 우측에 **[🚀 그룹 매칭 시작]** 및 **[🔄 매칭 초기화]** 버튼을 든든한 크기로 배치하여 관리자의 핵심 동선을 유도



### ⑤ 최종 매칭 결과 페이지 (`results.html`)

* **레이아웃:** 반응형 그리드 시스템(`row-cols-1 row-cols-md-3`)을 활용하여, 화면 크기에 따라 **1줄에 3개의 조 카드**가 격자 형태로 예쁘게 배치되는 레이아웃
* **UX 요소:**
* **조 카드 (Group Card):** * 카드 상단에 조 이름(예: `Backend Group 1`)과 대푯값 배지(`common_keywords`)를 포인트 컬러 배경의 태그 형태로 노출
* 카드 내부에는 조원들의 닉네임을 불릿 기호 없이 깔끔하게 리스트업
* 내 닉네임이 포함된 조 카드는 테두리가 조금 더 두껍거나 하이라이트 처리가 되어 한눈에 내 조를 찾을 수 있는 친절한 UX 제공





### ⑥ 인사이트 게시판 페이지 (`board.html` / `post_detail.html`)

* **UX 요소:**
* 전형적인 깔끔한 IT 커뮤니티 스타일로 구현
* 게시글 목록은 테이블 형태 대신, 한 줄씩 여백이 있는 **리스트 카드 형태**로 구현하여 최신 테크 블로그 같은 세련된 느낌 전달
* 글쓰기 버튼은 우측 상단에 직관적으로 배치
