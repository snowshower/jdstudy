# 📝 JD 분석 스터디 매칭 시스템 - 기능 요구사항 명세서

## 1. 회원 가입 및 크루 입력 (사용자 관점)

* **기능 설명:** 스터디에 참여하고자 하는 크루가 본인의 인적 사항과 학습 성향을 입력하고 등록하는 기능입니다.
* **상세 요구사항:**
* **입력 항목:** 크루명(닉네임), 비밀번호, 희망 직무(백엔드/프론트엔드/기타 중 택 1), 목표 기업(미리 제공된 목록에서 다중 선택하는 체크박스), 관심 기술 키워드(미리 제공된 목록에서 다중 선택하는 체크박스).
* **예외 처리:** 이미 DB에 존재하는 크루명으로 등록을 시도할 경우, "이미 등록된 크루명입니다. 로그인해 주세요."라는 안내 메시지를 출력합니다.
* **비밀번호 저장:** 입력된 비밀번호는 데이터베이스에 안전하게 저장됩니다.



## 2. 크루 로그인 (사용자 관점)

* **기능 설명:** 등록된 크루가 시스템에 접속하여 서비스를 이용하기 위한 인증 기능입니다.
* **상세 요구사항:**
* **인증 방식:** 최초 입력 시 설정한 '크루명'과 '비밀번호'를 입력하여 로그인합니다.
* **세션 유지:** 로그인 성공 시 FastAPI의 Cookie/Session 기능을 활용하여 브라우저를 닫기 전까지 로그인 상태를 유지합니다.
* **접근 제한:** 로그인하지 않은 사용자가 '매칭 결과'나 '인사이트 게시판' 페이지에 접근하려고 하면 로그인 페이지로 리다이렉트합니다.



## 3. 관리자 로그인 (운영자 관점)

* **기능 설명:** 스터디장(나)이 매칭 시스템을 제어하고 크루 현황을 관리하기 위한 마스터 인증 기능입니다.
* **상세 요구사항:**
* **인증 방식:** 지정된 마스터 계정(ID: `admin` / PW: `설정한 비밀번호`)으로 로그인합니다.
* **권한 분리:** 관리자로 로그인 성공 시, 일반 크루원에게는 보이지 않는 '관리자 전용 세션'을 부여합니다.



## 4. 관리자 그룹 매칭 기능 (운영자 관점)

* **기능 설명:** 관리자가 버튼 하나로 수집된 크루 데이터를 분석하여 스터디 조를 자동 편성하는 기능입니다.
* **상세 요구사항:**
* **관리자 대시보드 (`/admin`):** 현재까지 신청 완료한 크루원들의 명단을 표(Table) 형태로 실시간 모니터링합니다. 이 페이지는 오직 관리자 세션이 있을 때만 접근 가능합니다.
* **매칭 알고리즘 트리거:** 대시보드 하단의 **[그룹 매칭 시작]** 버튼을 누르면 작동합니다.
* **매칭 규칙 (로직):**
1. *1순위:* '희망 직무'가 일치하는 크루들을 먼저 묶습니다.
2. *2순위:* 같은 직무 내에서 '관심 기술 키워드'나 '목표 기업'이 유사한 크루들에게 가중치를 두어 우선적으로 한 조에 배치합니다.
3. *인원 제한:* 한 조당 **최소 4명 ~ 최대 5명**의 정원을 가집니다.
4. *예외 처리:* 매칭 교집합이 없는 낙오자는 동일 직무 조의 빈자리에 랜덤하게 분산 배치합니다.


* **결과 저장 및 시각화 (`/results`):** 매칭이 완료되면 조별 명단과 공통 분모(키워드)를 데이터베이스에 저장하고, 크루들이 볼 수 있는 결과 화면에 예쁘게 출력합니다.



## 5. 인사이트 공유용 게시판 (공통 기능)

* **기능 설명:** 스터디원들이 찾은 유용한 JD, 채용 공고, 기술 블로그 링크 등을 아카이빙하고 공유하는 소통 공간입니다.
* **상세 요구사항:**
* **접근 권한:** 로그인한 일반 크루원 및 관리자만 조회 및 작성이 가능합니다.
* **글 작성 항목:** 제목, 공유 링크(URL), 내용(인사이트/추천 이유), 태그 선택(예: `[채용공고]`, `[기술블로그]`, `[기타]`).
* **작성자 자동 연동:** 글 작성 시 작성자(닉네임) 필드는 현재 로그인된 세션의 크루명으로 자동 고정되어 도용을 방지합니다.
* **정렬:** 최근에 작성된 유용한 정보가 상단에 오도록 최신순으로 정렬하여 리스트를 보여줍니다.
